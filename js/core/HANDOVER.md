# 인수인계 — OZ 보안 패치 사이트 (forcsoz.github.io)

다음 관리자가 읽을 문서입니다. 코드를 몰라도 됩니다.

## 한 줄 요약
- 사이트(https://forcsoz.github.io)는 **화면과 암호문만** 있는 공개 저장소입니다. 첫 화면은 누구나 보는 **기술공지**입니다.
- 원본 자료(패치·링크·파일 정보·변경 기록)와 명단은 **비공개 저장소 `forcsoz/forcsoz-data`** 에 **암호화되어** 있습니다.
- 로그인은 하나: **아이디 + 코드**. 역할은 고르지 않고 아이디의 자리가 정합니다.
  - 유지보수고객: 고객 ID + 인증번호(회사 DB) · 컨설팅팀원/작성자/관리자: @forcs.com 주소 + 발급 코드
- PDF·PPTX 는 공개 저장소 `forcsoz/files-1, -2, …` 에 파일마다 다른 열쇠로 암호화되어 있습니다.
- PC 를 켜 두지 않아도 됩니다 (GitHub 가 보관).

## 꼭 보관할 것

| **관리자 아이디·코드** (oz@forcs.com + 코드) | 관리자 로그인 | 비밀번호 관리 앱 |
| **데이터 저장소 비밀번호** + **데이터 저장소 복구 코드** | 금고(forcsoz-data)를 여는 마지막 열쇠 | 봉투 |
| **명단 복구 코드** | 관리자 코드를 잃었을 때 새 코드를 받는 유일한 방법 | 봉투 |

데이터 저장소 비밀번호와 복구 코드를 모두 잃으면 아무도 원본을 열 수 없습니다 (게시된 화면은 남습니다).

## 자주 하는 일
- **팀원 추가**: 관리 › 사람·권한 › 주소·이름·역할 → 코드 발급 → 초대 글을 **그 사람의 @forcs.com 메일로** 보냅니다.
- **유지보수고객 인증번호 넣기**: 회사 DB 에서 `고객ID, 인증번호, 고객명, 제품` CSV 를 내보내 관리 › 사람·권한에 넣습니다. 40비트 미만(짧거나 순서대로 발급된) 번호는 거부·표시됩니다.
- **막기(철회)**: 명단의 "막기". 그 사람이 가진 등급 열쇠를 바꿔 바로 올립니다. 이미 받아 간 내용은 막을 수 없습니다. 작성자·관리자를 막았으면 **GitHub 토큰도 바꿉니다**.
- **고치고 게시**: 패치·제품·링크·파일을 고친 뒤 관리 › 게시. 게시해야 팀원·고객에게 보입니다 (1~2분).
- **토큰 바꾸기**(1년에 한 번, 또는 사람을 막았을 때): GitHub › Settings › Developer settings › Fine-grained token
  (저장소: forcsoz-data · forcsoz.github.io · files-*, Contents 읽기/쓰기, 새 파일 저장소를 만들려면 Administration 쓰기)
  → 관리 › 이 기기 · 계정 › GitHub 토큰 바꾸기 → 예전 토큰은 GitHub 에서 지웁니다.
- **관리자 코드를 잃었을 때**: 로그인 화면 › 처음 설정 · 관리자 복구 › "관리자 코드를 잃었어요" (데이터 저장소 비밀번호 + 명단 복구 코드).

## 지워지지 않는 것
- 모든 "삭제"는 휴지통입니다. 명단의 "막음"도 기록으로 남습니다. 저장소에서는 아무것도 지우지 않습니다 (git 기록이 곧 이력).
